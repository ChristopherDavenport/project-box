## What it found

- **The lander titles a pull request with the task** (#59). GitHub refuses
  a title over 256 characters; the first landing through the lander parked
  at the land step, two `box/` branches were pushed with no request behind
  them, and the lander was turned off for the rest of the round. Fixed by
  the round's own sixth unit.
- **A unit waiting on a section holds a seat.** With two seats, one wait
  idled every unit in another section; the cap went to three mid-round.
  The proper fix, a wait that holds no seat, is still open.
- **A reboot is a restart nobody asked for.** The daemon died with the
  machine; the waiting unit's built commit could not be rebased over the
  head that moved while it waited, and the builder ran again from scratch.
  The fence did what it should; the rebuild is the cost of a commit that
  waited long enough for its base to move.
- **The gate's check is not CI's check** (#68). The round's landings never
  saw CI, which runs on `main` and on pull requests only; the promotion PR
  was the first run, and it failed at gofmt on #59's test file in 47
  seconds. Generate, build and test is what the gate runs; gofmt, vet,
  race and govulncheck are what CI adds.
